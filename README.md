# COMP3011 Assignment 3 - Java Application and Demo

This folder contains both starter code for the web server component and the desktop video player
components of Assignment 3. NOTE: If you have completed Assignment 1 and Assignment 2 then it is
recommended you do not use this starter code - continue to develop what you already have and it
will probably save you time and effort. However, if you do not have working code for either
Assignment 1 or Assignment 2, you may want to read on to use this code.

Start by moving the web server component (SpeechToTextWebPage.zip) out of this folder and create a separate
project from the contents of that zip. Import this as a project into your Eclipse IDE to get started. It
contains it's on HELP.md file to get you started with a basic web server (that needs to be extended
for Assignment 3 as per the Specifications).

The remaing code is basic single threaded video player code to use as a starting point for your Assignment 3
development if you do not have a working video player from Assignment 2 that you wish to build upon.
It is recommended that you continue to build on your player from Assignment 2 but you will not be
penalised by using this code as a starting point instead.

For more information on this code and how to get started, see:

- the Hints, Tips and Tricks section of Assignment 1 at
https://learn.adelaide.edu.au/courses/30747/assignments/94504 for how to get started
with the web server code.

- first five steps of the Instructions for Assignment 2 at
https://learn.adelaide.edu.au/courses/30747/assignments/94505 for how to get started
with the video player.

- then you are ready for the instructions for Assignment 3 at
https://learn.adelaide.edu.au/courses/30747/assignments/94506

All the best!
